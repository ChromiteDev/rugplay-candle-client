# Contributing

Candle Client is **closed source**. The code is published so you can read it and install it easily, but it is not open for modification or redistribution. See LICENSE for the full terms.

## What we welcome

**Bug reports.** Open an issue with three things: what you did, what you expected, and what happened instead. Add your browser name and version if you can. A short description is better than a long one.

**Feature ideas.** Open an issue describing the mod you want. If it is backed by a real RugPlay endpoint, say which one. Ideas tied to real platform data always land first.

**Feedback.** The client is meant to feel like a desktop application. If something looks off or feels slow, say so.

## What we do not accept

- **Pull requests and code contributions.** The project is maintained by Chromites alone. The license does not permit redistribution or modification, so pull requests cannot be merged.
- **Copies or forks for redistribution.** Do not host mirrors of the userscript or resell it.

## Ground rules

- One issue per bug or idea.
- Keep reports specific and reproducible.
- By opening an issue, you agree it may be used to improve the client.

The fastest way to reach the maintainer is through the issues tab. Thank you for playing fair with the license.
